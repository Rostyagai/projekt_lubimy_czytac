## 🧠 Logika i Architektura projektu

### 1. Integracja z Firebase
Aplikacja wykorzystuje system **Firebase** do zarządzania danymi. Dzięki temu użytkownicy mogą korzystać z dynamicznych treści, które są synchronizowane w czasie rzeczywistym. Wykorzystaliśmy Firestore do przechowywania informacji o książkach.

### 2. Komponentowość (React)
Aplikacja została podzielona na reużywalne komponenty. Pozwala to na zachowanie czystości kodu i łatwą rozbudowę poszczególnych sekcji strony bez wpływania na resztę systemu.

### 3. Szybkość dzięki Vite
Zastosowanie **Vite** zamiast standardowych rozwiązań pozwoliło na błyskawiczne ładowanie aplikacji podczas pracy nad nią oraz bardzo szybkie działanie wersji końcowej dla użytkownika.

### 4. Design i UX
Każda sekcja została starannie zaplanowana przez **Kirę Hrypko**, aby strona była przejrzysta i zachęcała do interakcji. Skupiliśmy się na tym, aby design nie tylko ładnie wyglądał, ale był też funkcjonalny.

## 🛠️ Instalacja i uruchomienie

Aby uruchomić projekt lokalnie:

1.  Sklonuj repozytorium:
    ```bash
    git clone https://github.com/Rostyagai/projekt_lubimy_czytac.git
    ```
2.  Wejdź do folderu:
    ```bash
    cd projekt_lubimy_czytac
    ```
3.  Zainstaluj biblioteki:
    ```bash
    npm install
    ```
4.  Uruchom projekt:
    ```bash
    npm run dev
    ```
